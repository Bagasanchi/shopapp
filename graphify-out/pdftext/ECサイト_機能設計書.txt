1. 概要 
1.1 システムの構成 
ブラウザから送られたリクエストを Servlet が受け取り、DAO を使ってデータベースを操作し、結果を JSP に渡して画
面を作ります（MVC モデル）。 
役割 作るもの 内容 
画面（View） JSP（WEB-INF の中） Servlet から受け取った値を HTML にして表示する 
処理（Controller） Servlet（servlet パッケージ） リクエストを受け取り、入力のチェック、DAO の呼び出
し、画面の切りかえを行う 
データ（Model） model・dao・util パッケージ model はデータを入れるクラス、DAO はデータベースを
操作するクラス、util は共通の部品 
データベース MySQL の shopdb テーブルは DB定義書のとおり 
1.2 前提 
利用者・機能・制約は要件定義書を、画面と項目・メッセージは画面設計書を見てください。この文書の機能 ID
（F-xx）・画面 ID（S-xx）・メッセージ ID（M-xx）は、それらの文書と同じ番号です。

2. 共通のルール 
2.1 プロジェクトの構成 
動的 Webプロジェクト shopapp を作り、次の構成にします。URL は 
http://localhost:8080/shopapp/products のようになります。 
場所 置くもの 
src/main/java/util DBManager、Validator（どちらも配布ファイル） 
src/main/java/model Product、Category、User、Order、Sales、Delivery、
StandardDelivery、ExpressDelivery 
src/main/java/dao ProductDAO、CategoryDAO、UserDAO、OrderDAO 
src/main/java/servlet Servlet のクラス（3章の表） 
src/main/java/main Main（DAO の動きをコンソールで確かめるクラス） 
src/main/webapp/WEB-INF JSP ファイル（ブラウザから直接開けないように、ここに置く） 
src/main/webapp/WEB-INF/lib jar ファイル 3つ（MySQL Connector/J、JSTL の API と実装） 
src/main/webapp/css style.css（配布ファイル。WEB-INF の中には置かない） 
 
2.2 プログラムを書くときのルール 
・ データベースへの接続は、DBManager.getConnection() を使う 
・ 入力チェックは、配布ファイルの Validator を使う（商品の登録は validateProduct、注文の数量は 
validateOrder）。返ってきたエラーメッセージの List が空でなければ、入力画面に戻す 
・ DAO のメソッドは、すべて throws SQLException を付ける。Servlet では try-catch で受け取り、catch 
の中で e.printStackTrace(); を呼ぶ 
・ SQL に値を入れるときは、必ずプレースホルダ（?）を使う 
・ 登録・削除・更新が終わったら、リダイレクトで一覧画面に移る（注文は除く） 
・ model のクラスを作ったら、Main で DAO のメソッドを呼び出して、正しく動くか確かめる 
2.3 JSP の作り方のルール 
・ JSP はすべて src/main/webapp/WEB-INF の中に置き、Servlet からフォワードして表示する 
・ 1行目に <%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %> 
を書く 
・ JSTL（<c:forEach>、<c:if>）を使う JSP は、2行目に <%@ taglib prefix="c" 
uri="jakarta.tags.core" %> を書く 
・ <head> に <meta charset="UTF-8">、<title>、<link rel="stylesheet" 
href="css/style.css"> を書く 
・ リンクの href やフォームの action は、products のように / を付けずに書く 
CSS（style.css）で使う class は次の 3つです。表・フォーム・ボタン・見出しは、タグを書くだけで見た目が付き5 
ます。 
class 付ける場所 見た目 
customer 購入者の画面（S-06〜S-09）の <body> 見出し・表の見出し行・ボタン・リンクがオレンジに
なる。管理者の画面は class を書かない
（紺） 
error エラーメッセージの <p> 赤い文字 
success 完了メッセージの <p> 緑の太字 
画面の部品 タグ 
タイトル・見出し <h1>（1画面に 1つ）、小見出しは <h2> 
一覧の表 <table>。1行目は <th> の見出し行、2行目からは <c:forEach> で繰り返す 
詳細の表 <table>。1行に <th>（項目名）と <td>（値）を 1つずつ 
入力・選択 <label> で <input> や <select> を囲む 
ボタン <button type="submit">（フォームの中に置く） 
リンク・メッセージ <p> の中に書く 
2.4 メッセージ 
画面に表示するメッセージの文字は、画面設計書 2.2 のとおりにします。この文書では、メッセージを ID（M-xx）
で書きます。
